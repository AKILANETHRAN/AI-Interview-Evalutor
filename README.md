# AI Interview Evaluator Using NLP

> **Practice. Analyze. Improve.**  
> An automated mock technical interview evaluation system powered by classical Natural Language Processing (NLP), Flask, SQLite, and Chart.js.

The complete application is located in the [`ai-interview-evaluator/`](./ai-interview-evaluator/) directory.

### Quick Start
```bash
# 1. Navigate to application folder
cd ai-interview-evaluator

# 2. Run the application
python app.py
```
Open **[http://127.0.0.1:5000](http://127.0.0.1:5000)** in your browser.

Alternatively, you can launch directly from the root repository:
```bash
python run.py
```

### Run Automated Tests
```bash
cd ai-interview-evaluator
python -m unittest tests/test_app.py
```
All 17 tests pass with 100% success!

For comprehensive documentation on system architecture, NLP pipeline, database schema, viva questions, and deployment instructions, see [`ai-interview-evaluator/README.md`](./ai-interview-evaluator/README.md).
